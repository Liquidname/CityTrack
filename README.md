# CityTrack

Мобильная аркада для WebGL — летим над городом, ныряем между крышами и зданиями, набираем очки и прокачиваем персонажа.

## Геймплей

Игрок управляет планирующим персонажем одним касанием/кликом:

- **Отпустить** — персонаж расправляет крылья, разгоняется и плавно снижается
- **Зажать** — пикирование вниз с ускорением
- Отскоки от **платформ на крышах** и внутри зданий дают очки и поддерживают скорость
- Пролёт в **окна** переключает слой полёта: крыши ↔ здания
- Потеря скорости или падение ниже уровня земли — **поражение**

На определённой дистанции включается **встречный ветер** — второй секция карты с усиленным сопротивлением.

## Прогрессия

Между забегами открывается магазин апгрейдов за заработанные монеты:

| Улучшение | Эффект |
|---|---|
| Max Speed | Увеличивает максимальную горизонтальную скорость |
| Armor | Снижает потерю скорости при столкновении с препятствием |

## Технологии

- **Unity** (WebGL)
- **VContainer** — DI-контейнер
- **3D-коллайдеры** для физики столкновений

## Архитектура

### DI и точка входа

Основа — **VContainer**. Весь проект живёт в одном `Level1Scope` (`LifetimeScope`), без глобальных синглтонов и `FindObjectOfType`. View-компоненты со сцены регистрируются через `RegisterComponent`, сервисы — как `Singleton`.

Единственная точка входа — `Level1EntryPoint` (`IStartable` / `ITickable` / `IDisposable`). Все `Start()` систем вызываются вручную из него, а не разбросаны по `MonoBehaviour.Awake`.

### Игровой цикл

Нет независимых `MonoBehaviour.Update()` в игровой логике. Всё обновление идёт через `Level1EntryPoint.Tick()` в жёстком порядке:

```
MovementSystem → GameStateMachine → MapGeneratorSystem
→ CameraSystem → ParallaxSystem → ScoreSystem
```

Интерфейс `IGameTick` реализуют все системы, которым нужен Tick. `IGameStart` — те, кому нужна явная инициализация.

### Стейт-машина

`GameStateMachine` резолвит состояния через DI-контейнер (singleton-экземпляры, без аллокаций при переходах):

```
PrepareState ──(клик)──► StartSection ──(дистанция ≥ 500м)──► SecondMapSectionState
                                                                        │ (Defeated)
PrepareState ◄──(клик)── DefeatState ◄──────────────────────────────────┘
```

- **PrepareState** — сброс карты, очков, апгрейдов; показ магазина
- **StartSection** — старт движения; мониторинг дистанции
- **SecondMapSectionState** — активация встречного ветра (нарастающий `WindDrag`) и VFX
- **DefeatState** — остановка движения; ожидание рестарта

### Модель движения

Игрок зафиксирован по X — карта едет навстречу. Два режима:

- **GLIDE** (ЛКМ отпущена) — плавное снижение, разгон за счёт угла и подъёмной силы
- **DIVE** (ЛКМ зажата) — пикирование с гравитацией и торможением по X

Скорость влияет на отскок от платформ: слишком медленно — поражение. Модификаторы из магазина (бонус скорости, броня, ветер) хранятся в `MovementStats` отдельно от базовых `MovementSettings`.

### Карта и пулы

`MapGeneratorSystem` конвейерно спавнит/утилизирует чанки зданий через `ChunkPool` и `PlatformPool` (`ObjectPool<T>`). Триггеры в сцене (`SpawnTriggered` / `DestroyTriggered`) сигнализируют о смене чанка — никакого поиска объектов в Tick.

### Прочие системы

| Система | Что делает |
|---|---|
| `CameraSystem` | Следование за игроком по Y с мёртвой зоной и разным сглаживанием вверх/вниз |
| `ParallaxSystem` | Бесконечный скроллинг фоновых слоёв, пропорциональный `VelocityX` |
| `ScoreSystem` | Пассивные очки за дистанцию + комбо-множитель за платформы |
| `UpgradeSystem` | Магазин апгрейдов между забегами, покупки в пределах сессии |
| `AudioSystem` | Тонкая обёртка над `AudioSource` для SFX |
